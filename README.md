# WoWS Explorer

A frontend test project for browsing ships available in World of WarShips.

## Tech stack

- Vue 3
- TypeScript
- Vite
- SCSS
- Vitest

## Code quality

- EsLint
- Prettier

## Requirements

- Node.js 22+
- npm

## Setup

- Install dependencies:

```bash
npm install
```

- Run the development server:

```bash
npm run dev
```

- build for production:

```bash
npm run build
```

- Run linting:

```bash
npm run lint
```

- Check formatting:

```bash
npm run format:check
```
