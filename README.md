# WoWS Explorer

A frontend test project for browsing ships available in World of WarShips.

## Tech ctack
- Vue 3
- TypeScript
- Vite
- Vitest

## Requirements
- Node.js 22+

## Setup
- Install dependencies: 
```bash
npm install
```

- Run the development server:
```bash
npm run dev
```

- build for production:
```bash
npm run build
```
